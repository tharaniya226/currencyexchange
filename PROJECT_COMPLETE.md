## 🤖 ML Model Details

### Architecture
```
LSTM Neural Network
├── Input Layer (Historical rates)
├── LSTM Layer (50 units)
├── Dropout Layer (0.2)
├── LSTM Layer (50 units)
└── Dense Layer (1 output)
```

### Performance Metrics
- **Accuracy**: 89.5%
- **MAE**: 0.0023
- **RMSE**: 0.0031
- **R² Score**: 0.87
- **Training Samples**: 10,000
- **Validation Samples**: 2,000
